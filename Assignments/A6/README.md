## Task 2: Naive RAG vs Contextual Retrieval

### Naive RAG
1. Chunks are embedded as-is using `all-MiniLM-L6-v2`
2. FAISS index built with `IndexFlatIP` (cosine similarity)
3. Top-3 chunks retrieved per query
4. Retrieved chunks passed directly to Qwen as context for answer generation

### Contextual Retrieval
1. Each chunk is enriched with a **1–2 sentence context prefix** generated by Qwen:
   > *"This chunk from Chapter 2 discusses [explanation of chunk's role in the document]."*
2. Enriched chunk text (`context_prefix + original_text`) is embedded
3. FAISS index built on enriched embeddings
4. Top-3 enriched chunks retrieved and passed to Qwen for generation

**Before enrichment:**
> *"The most frequent neighboring pair of characters is 'A B' so we merge those..."*

**After enrichment:**
> *"This chunk from Chapter 2 discusses the BPE training algorithm's iterative merge process.*
> The most frequent neighboring pair of characters is 'A B' so we merge those..."*

## Evaluation Results (ROUGE Scores)

Evaluated over **20 QA pairs** against ground truth answers.

| Method | ROUGE-1 | ROUGE-2 | ROUGE-L |
|--------|---------|---------|---------|
| Naive RAG | 0.1978 | 0.0845 | 0.1570 |
| **Contextual Retrieval** | **0.2248** | **0.1145** | **0.1832** |

### Discussion

Contextual Retrieval outperforms Naive RAG across all three ROUGE metrics:

- **ROUGE-1 (+0.0270):** Contextual chunks contain richer vocabulary aligned with query terms due to the prepended context prefix, improving unigram overlap.
- **ROUGE-2 (+0.0300):** The most notable gain — bigram precision improved significantly, suggesting retrieved chunks were more precisely relevant to each question.
- **ROUGE-L (+0.0262):** Longest common subsequence improved, indicating answers were more structurally aligned with ground truth.

The main reason for improvement is that the context prefix explicitly situates each chunk within the document. For example, a chunk about BPE merging steps alone gives no indication it discusses BPE — but the enriched version begins *"This chunk discusses the BPE training algorithm..."*, making it far more likely to be retrieved for BPE-related queries.

Limitations: ROUGE scores are relatively low overall because Qwen 3B generates paraphrased answers rather than extractive ones, and ROUGE penalises paraphrasing. Semantic similarity metrics (e.g. BERTScore) would likely show a larger advantage.

## Task 3: Streamlit Web Application

### Running the App

```bash
cd app
# Make sure contextual_chunks.json is in this folder
python -m streamlit run app.py
```

Then open `http://localhost:8501` in your browser.

### Features
- Chat interface for asking questions about Chapter 2
- Backend uses **Contextual Retrieval** (same pipeline as Task 2)
- Every answer displays an expandable **"Source chunks used"** section showing:
  - Chunk ID and paragraph ID
  - Similarity score
  - 🏷️ Context prefix (the enrichment sentence)
  - Original chunk text preview
